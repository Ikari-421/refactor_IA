explication: >-
  Vous baissez le feu. Le liquide frémit à peine : quelques bulles, pas une ébullition vive.
  Souvent vous couvrez. Les aliments cuisent dans ce liquide chaud ; le but n’est pas de faire baisser le niveau.
  C’est réussi quand c’est cuit ou bien chaud, selon la recette, et que ça n’attache pas.
